# Typography

The application uses Instrument Sans and Instrument Serif from Google Fonts through
Next.js font optimization. Both use the SIL Open Font License 1.1. The original
copyright/license notices are preserved in `public/licenses/instrument-sans.txt`
and `public/licenses/instrument-serif.txt`. No font files were modified.

License sources:
- https://github.com/google/fonts/blob/main/ofl/instrumentsans/OFL.txt
- https://github.com/google/fonts/blob/main/ofl/instrumentserif/OFL.txt
